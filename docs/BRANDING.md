## Trademark search checklist (do before committing to any name, logo or domain)

- [ ] **CIPO** – Canadian Trademarks Database: https://ised-isde.canada.ca/cipo/trademark-search/srch/
- [ ] **USPTO** – trademark search (replaced TESS): https://tmsearch.uspto.gov/
- [ ] **WIPO Global Brand Database**: https://branddb.wipo.int/
- [ ] Search phonetic and spelling variants, translations, and similar-sounding marks, not just exact matches
- [ ] **Nice classes**: **9** (downloadable software/apps), **28** (games and playthings), **41** (online entertainment / non-downloadable games)
- [ ] Domain availability (.com, .ca, .app) and no confusingly similar active site
- [ ] App stores: Apple App Store, Google Play – search for conflicting app names/developers
- [ ] Social handles: X, Instagram, TikTok, YouTube, Facebook, Discord, Reddit
- [ ] General web search for existing use of the name in gaming/gambling (common-law rights count)
- [ ] Check the logo/artwork separately (reverse image search; avoid card-suit/slot-machine clichés that look like others' marks)
- [ ] **Consult a trademark agent or lawyer** (in Canada, a registered trademark agent) before filing or launching

### Checks that could not be automated (do these manually)

- **CIPO Canadian Trademarks Database** (the search page is JavaScript-driven; results could not be pulled automatically): https://ised-isde.canada.ca/cipo/trademark-search/srch . Search each name as "Trademark" (word), with Nice class filter 9, 28, 41 (also try 42), status "All active", then repeat with phonetic/spelling variants (e.g. Tallowtide / Tallow Tide / Talo-tide).
- **USPTO trademark search** (JavaScript app, no scriptable output): https://tmsearch.uspto.gov/ (use "Basic word mark search", then check live and dead records).
- **WIPO Global Brand Database** (bot challenge blocks scripts): https://branddb.wipo.int/ (brand name search; include Canada, US, EU, UK, Madrid designations).
- **Instagram and TikTok handles**: not checkable without logging in (the sites return the same page for any name). Check https://www.instagram.com/<name>/ and https://www.tiktok.com/@<name> in a browser.
- **Apple App Store / Google Play**: only web-search results were used. Search by hand at https://apps.apple.com/ and https://play.google.com/store/search?c=apps&q=<name> (and developer names).
- **.ca registration**: DNS only; confirm at a CIRA-accredited registrar (https://www.cira.ca/). Canadian .ca registration requires Canadian presence (Bavi qualifies).
- **Logo/artwork**: not screened (reverse image search needed once a logo exists).

### Notes on filing in Canada

- A Canadian trademark application can be filed **while the app is free-play**. Canada no longer requires proof of use before registration, but the mark must be used in Canada, in association with the goods/services, eventually (and can be attacked for non-use after 3 years). Common-law use also creates rights.
- Likely **Nice classes: 9** (downloadable game software/apps), **28** (games and playthings, if any physical/tabletop products), **41** (online entertainment / non-downloadable games). Class 42 (hosting software) may also be relevant. A trademark agent can advise on the wording; keep descriptions to "free-to-play, no-purchase, no-prize" games.
- Filing is done by **Bavi (or a registered trademark agent)** via CIPO, not by this assistant. Fees are per class; check the current CIPO fee schedule.
- A **real-money** version later would be a different regulatory matter: it would require a licensed operator and registration with **AGLC / iGaming Alberta**. Choose a name that does not suggest gambling or prizes now so it does not cause trouble later.
